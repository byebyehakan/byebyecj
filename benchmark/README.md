# Benchmark

Bu klasör, ByebyeCJ için örnek benchmark kullanımını barındırır.

Örnek:

```bash
dart run tool/benchmark.dart
```

Amaç:
- yazma hızı
- okuma hızı
- indeks sorgu performansı
- tam tarama karşılaştırması
- cleanup/compaction süresi

Bu klasör boş kalmaması için örnek kullanım notu eklendi.
